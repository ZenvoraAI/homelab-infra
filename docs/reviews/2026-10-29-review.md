Reviewed by Claude directly, including the cross-repo questions left open by the 2026-10-29 reviews
of day-and-you, aiqiuqi-memorial and family-media. Offline tests (`tests/*.sh` on a clean export of
origin/main): all pass; `verify-handoff-env.sh` fails only outside the real checkout because it

## Findings

1. **MEDIUM — day-and-you product photos over 1 MB cannot be uploaded.** `nginx/conf.d/dayandyou.conf`
   sets no `client_max_body_size` and `nginx/nginx.conf` has none at `http` level, so nginx's 1 MB
   default applies, while the app accepts 5 MB
   (`day-and-you/app/api/admin/products/[id]/images/route.ts:15`) and the admin uploader does not
   compress (`day-and-you/components/admin/ImageUploader.tsx:39-53`). Measured on staging
   2026-10-29: an unauthenticated 500 KB POST to `/api/admin/products/x/images` reached the app
   (401), a 2 MB POST got **413** from nginx. The uploader then fails to parse the HTML 413 page and
   shows "Network error. Please try again." Fix: `client_max_body_size 6m;` in both dayandyou server
   blocks (staging + prod), and make the uploader report a non-JSON error status.
2. **LOW — no `Permissions-Policy` on the proxied hosts** (admin.valtou.com, api.valtou.com,
   api.aiqiuqi.com). Harmless for JSON APIs; admin.valtou.com should set it in the app
   (see zenvora-admin review).

## Cross-repo questions — answered

- **Can the app ports be reached directly, bypassing nginx's `X-Real-IP`?** No. From outside on
  2026-10-29, `3.26.252.132` accepts only 22/80/443; 3000–3003, 3100, 4000, 5432 and 2375 are
  closed or filtered.
- **Is `X-Real-IP` always overwritten by nginx?** Yes. Every proxied server block sets
  `proxy_set_header X-Real-IP $remote_addr` at server level with no location-level
  `proxy_set_header` that would drop the inheritance (`valtou-api.conf:19-24`, `family-api.conf:16-19,62-65`,
  `api.aiqiuqi.com.conf:16-19`, `dayandyou.conf:10-15,45-50`), and `$remote_addr` is restored from
  `CF-Connecting-IP` only for Cloudflare ranges (`00-cloudflare-realip.conf`).
- **memorial-worker memory vs the 50 MP HEIC cap:** origin/main has `mem_limit: 512m` (`d864df6`),
  matching aiqiuqi-memorial `0212a5d`. The local checkout is on `fix/securevault-api-memory`, which
  predates that commit.
- **Upload body limits elsewhere:** family-api and api.aiqiuqi.com set 4 MB; both apps upload media
  straight to S3 with presigned requests, so that is enough.
